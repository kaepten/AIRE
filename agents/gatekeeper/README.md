## Getting Started
AGENTS.md ist eine standardisierte Markdown-Kontextdatei, die dem KI-Coding-Agenten Junie (von JetBrains) projektspezifische Anweisungen, Regeln und Befehle übermittelt. AGENTS.md Datei konfigurieren im Verzeichnis ablegen: %USERPROFILE%\.junie\AGENTS.md 

Das kann auch für Projekte spezifisch im jeweiligen Projektordner abgelegt werden: \MeinProjekt\.junie\AGENTS.md
